# tor-review: นักวิเคราะห์ตรวจสอบ TOR การจัดซื้อจัดจ้างภาครัฐไทย

สกิล (Claude Agent Skill) สำหรับช่วยตรวจ **TOR** (ร่างขอบเขตของงาน / รายละเอียดคุณลักษณะเฉพาะของพัสดุ) ในการจัดซื้อจัดจ้างภาครัฐไทยเบื้องต้น จุดเด่นคือ **ทุกข้อสังเกตต้องบอกได้ว่าอ้างจากกฎหมายหรือระเบียบข้อไหน พร้อมลิงก์ไปยังแหล่งทางการ** เพื่อให้ผู้ใช้ตรวจสอบย้อนได้เอง

> **ไม่ใช่คำปรึกษาทางกฎหมาย** ผลการตรวจเป็นเพียงข้อสังเกตเบื้องต้น ดูหัวข้อ "ข้อจำกัดและคำปฏิเสธความรับผิด" ด้านล่าง

## สกิลนี้ทำอะไร

- รับ TOR เป็น PDF, Word หรือข้อความ
- สรุปข้อมูลพื้นฐาน (วงเงิน วิธีจัดซื้อ ประเภทพัสดุ เกณฑ์พิจารณา)
- ตรวจตามรายการตรวจ 27 ข้อ (C-01 ถึง C-27) ใน 10 หมวด เช่น
  - องค์ประกอบ TOR ตามหนังสือ ว 159/2566
  - การระบุยี่ห้อหรือสเปกใกล้เคียงยี่ห้อ (พ.ร.บ. ม.9)
  - คุณสมบัติผู้ยื่นข้อเสนอ (ม.64) และผลงานที่อาจสูงเกินจำเป็น
  - เกณฑ์การพิจารณา (ม.65, ระเบียบข้อ 83)
  - ราคากลางและการเปิดเผย (ม.4, ม.63)
  - การรับฟังความคิดเห็นตามวงเงิน (ระเบียบข้อ 45–47, ว 210/2569)
  - หลักประกัน (ระเบียบข้อ 168)
  - พัสดุที่รัฐส่งเสริม: SME, นวัตกรรม, Made in Thailand (กฎกระทรวง พ.ศ. 2563 และที่แก้ไขเพิ่มเติม)
  - การแบ่งซื้อแบ่งจ้าง (ระเบียบข้อ 20) และผลประโยชน์ทับซ้อน (ม.13, ระเบียบข้อ 27)
- ออกรายงานรูปแบบเดียวกันทุกครั้ง: สรุปผล, ตารางข้อสังเกต (รหัส | ตำแหน่งใน TOR | ข้อความที่พบ | ปัญหา | ระดับ | อ้างอิง | ข้อเสนอแก้), ข้อแนะนำเชิงปฏิบัติที่ไม่มีข้อบังคับรองรับ (แยกชัด), รายการที่ไม่พบปัญหา, สิ่งที่ตรวจไม่ได้ และข้อจำกัด

หลักการของสกิล:
- ใช้คำว่า "ข้อสังเกต/ความเสี่ยง" ไม่กล่าวหาว่าผู้ใดทุจริต
- ห้ามแต่งเลขมาตรา ข้อ หรือตัวเลข ใช้เฉพาะแหล่งใน `references/sources.md`
- แหล่งที่ยืนยันได้เพียงบางส่วนต้องบอกระดับความมั่นใจ แหล่งที่ยืนยันไม่ได้ห้ามใช้เป็นเกณฑ์

## วิธีติดตั้ง

### Claude.ai (เว็บหรือแอป)
1. ดาวน์โหลด repo นี้แล้วบีบอัดโฟลเดอร์ `tor-review` เป็นไฟล์ zip (ให้ `SKILL.md` อยู่ในโฟลเดอร์ `tor-review` ภายใน zip)
2. ไปที่ **Settings → Capabilities** แล้วหาส่วน **Skills**
3. อัปโหลดไฟล์ zip และเปิดใช้งานสกิล

(ชื่อเมนูอาจเปลี่ยนตามเวอร์ชันของ Claude.ai)

### Claude Code
คัดลอกโฟลเดอร์ทั้งหมดไปไว้ที่ `~/.claude/skills/tor-review/`

```bash
mkdir -p ~/.claude/skills
cp -r tor-review ~/.claude/skills/
```

ตรวจว่ามีไฟล์ `~/.claude/skills/tor-review/SKILL.md` แล้วเริ่มเซสชันใหม่

## วิธีใช้

แนบไฟล์ TOR หรือวางข้อความ แล้วพิมพ์ เช่น

- "ช่วยตรวจ TOR นี้หน่อย"
- "ร่างขอบเขตงานนี้มีจุดไหนเสี่ยงล็อกสเปกไหม"

ถ้ามีเอกสารประกอบ เช่น ร่างประกาศเชิญชวน ตารางราคากลาง หรือคำสั่งแต่งตั้งคณะกรรมการ ให้แนบมาด้วย สกิลจะตรวจได้ครบขึ้น ดูตัวอย่างผลลัพธ์ที่ `examples/sample-report.md`

## ข้อจำกัดและคำปฏิเสธความรับผิด

- สกิลนี้เป็น **เครื่องมือช่วยตรวจเบื้องต้น** ผลลัพธ์ **ไม่ใช่คำปรึกษาหรือคำวินิจฉัยทางกฎหมาย** ไม่ใช่ความเห็นของหน่วยงานรัฐใด และไม่ใช่การกล่าวหาบุคคลหรือหน่วยงานใด
- แหล่งอ้างอิงตรวจ ณ วันที่ 2026-11-01 กฎหมาย ระเบียบ และหนังสือเวียนเปลี่ยนแปลงบ่อย **ก่อนใช้งานจริงต้องตรวจฉบับล่าสุด** ที่ https://www.gprocurement.go.th และราชกิจจานุเบกษา
- บางแหล่งยืนยันได้เพียงบางส่วน (เช่น อ่านได้บางหน้า หรือเห็นเพียงชื่อเรื่อง) สกิลจะบอกระดับความมั่นใจไว้ในรายงาน
- บัญชีแหล่งอ้างอิงไม่ได้ครอบคลุมทุกหลักเกณฑ์ที่เกี่ยวข้อง เช่น ประกาศคณะกรรมการนโยบายบางฉบับ และหลักเกณฑ์มูลค่าผลงานในงานก่อสร้างที่ยังหาต้นฉบับทางการไม่พบ
- โมเดลภาษาอาจอ่านเอกสารผิดหรือสรุปคลาดเคลื่อนได้ ผู้ใช้ควรตรวจข้อความใน TOR และตัวบทตามลิงก์ด้วยตนเองทุกครั้ง
- ผู้จัดทำไม่รับผิดชอบต่อความเสียหายใดๆ ที่เกิดจากการใช้ผลการตรวจนี้ สำหรับเรื่องที่มีผลทางกฎหมาย ควรปรึกษาเจ้าหน้าที่พัสดุ ฝ่ายกฎหมายของหน่วยงาน หรือผู้เชี่ยวชาญ

## English summary

**tor-review** is a Claude Agent Skill that performs a preliminary review of Thai public procurement TOR documents (scope of work / technical specifications). It checks 27 items across 10 categories, including brand-specific specifications (Procurement Act B.E. 2560, s.9), bidder qualifications (s.64), evaluation criteria (s.65, Regulation cl.83), reference price disclosure (s.63), public hearing periods (Regulation cl.45–47, CGD letter W 210/2026), bid security caps (cl.168), and SME / innovation / Made in Thailand preferences. Every observation must cite a specific section or clause with a link to an official source listed in `references/sources.md` (accessed 2026-11-01).

- **Install (Claude.ai):** zip the `tor-review` folder and upload it under Settings → Capabilities → Skills.
- **Install (Claude Code):** copy the folder to `~/.claude/skills/tor-review/`.
- **Disclaimer:** This is not legal advice. Laws and circulars change; always verify against the latest versions at gprocurement.go.th and the Royal Gazette.
